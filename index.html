Based on technical parameters, the answer to '" + userMsg + "' requires deep analysis. (Pro Mode Active)"; } else if (version.equalsIgnoreCase("Guide")) { response = " [Leo Guide]: Let me explain simply. You asked about '" + userMsg + "'. Think of it like this... (Step-by-step Guide Active)"; } else if (version.equalsIgnoreCase("Quickly answer")) { response = " [Leo Quick]: Answer: " + userMsg + ".
